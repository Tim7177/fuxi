1. 反比例函数的增减性：必须加「在每个象限内」（概念 · 易错）

图象位置增减性
k > 0第一、三象限在每个象限内，y 随 x 增大而减小
k < 0第二、四象限在每个象限内，y 随 x 增大而增大

易错：两个点不在同一个象限，不能直接用增减性比较。

  • 作业 93 第 5 题（你选 B，正确答案 A）：y = k/x（k>0），A(−1, y₁)、B(1, y₂)、C(2, y₃)。
    A 在第三象限，y₁ < 0；B、C 在第一象限，y > 0，所以 y₁ 最小。
    B、C 同在第一象限，x 越大 y 越小，所以 y₃ < y₂。结论：y₁ < y₃ < y₂。
  • 最稳的办法：直接代数算。令 k = 1：y₁ = −1，y₂ = 1，y₃ = 0.5，一眼看出来。

已知 x 的范围，求 y 的范围（作业 75 第 5 题，你选 C，正确答案 D）：
y = −6/x，1 < x < 3。先代入两个端点：x = 1 时 y = −6，x = 3 时 y = −2。
1 < x < 3 在同一个象限里，函数单调，所以 −6 < y < −2。

口诀：先代端点，再看单调；区间里包含 0 时要拆成两段分别算。

2. k 的几何意义和 k 的符号（规律 · 易错）

  • 过双曲线上一点向两条坐标轴作垂线：矩形面积 = |k|；和原点连成的三角形面积 = |k|/2。
  • 由面积只能求出 |k|，还要看图象在哪个象限来定正负。

作业 93 第 7 题（你选 C，正确答案 A）：B 在 y = 5/x 上，C 在 y = −1/x 上，BC ⊥ y 轴，A 在 x 轴上。
△ABC 的底是 BC，高是 B 到 x 轴的距离。底 × 高 = 两个矩形面积之和 = 5 + 1 = 6，
三角形还要乘 ½：S = ½ × 6 = 3。你选 6，是把矩形面积当成了三角形面积。

作业 93 第 15 题（你写 4，正确答案 −6）：图象在第二象限，k 一定是负数。
设 OB = AB = a，∠AOB = ∠BAO = 30°，所以 ∠ABO = 120°，OA = √3·a。
A 的坐标：横坐标 −(3/2)a，纵坐标 (√3/2)a。
S△ABO = ½ · a · (√3/2)a = 2，得 a² = 8/√3。k = x·y = −(3√3/4)a² = −6。

⚠️ 作业 93 第 13 题老师没打红，但图中 A 在第二象限，按同样道理 k 应该是 −6，你写的是 6，请对一下老师的答案。

作业 75 第 16 题（正确答案 4）：设 A(a, k/a)。B 在直线 OA 上，所以 B 的坐标和 A 成比例：B = (ta, tk/a)。
代入 y = k/(4x)，得 t² = 1/4，B 在另一侧，t = −½，即 OB = ½·OA。
AO = AC，所以 C(2a, 0)。S△AOC = ½ · 2a · (k/a) = k，S△BOC = ½ · 2a · (k/2a) = k/2。
S△ABC = k + k/2 = 3k/2 = 6，k = 4。

由图象判断 k 的范围（作业 75 第 6 题，你选 A，正确答案 B）：
先看象限定符号（二、四象限 → k < 0，5 和 12 都排除），再把图里虚线标出的点代进去，
按「曲线在这个点的上方还是下方」列 k 的不等式，最后在选项里找满足条件的值。

3. 分类讨论：同一象限 / 不同象限（作业 75 第 18 题）

(1) k > 0，P(m, y₁)、Q(−3, y₂)，且 y₁ > y₂，求 m。（你写 m > −3，正确答案 m < −3 或 m > 0）

  • Q 在第三象限，y₂ < 0。
  • 情况一：P 在第一象限（m > 0），y₁ > 0 > y₂，一定成立 ✅
  • 情况二：P 在第三象限（m < 0），和 Q 在同一象限，y 随 x 增大而减小。要 y₁ > y₂，就要 m < −3。
  • 你的两个问题：漏了情况一；情况二里把方向弄反了。

(2) 当 a ≤ x ≤ 2 时，y = k/x 既无最大值也无最小值，求 a。（正确答案 a < 0）

  • 如果 0 < a < 2，区间在同一象限，两端点就是最值，有最大值也有最小值，不符合题意。
  • 只有区间跨过 x = 0（x = 0 处没有定义，函数值趋于无穷大），才既无最大值也无最小值，所以 a < 0。

4. 待定系数法（作业 75 第 17 题，正确答案 y = 2x − 3/x）

y₁ 是 x 的正比例函数，y₂ 是 x 的反比例函数，就分别设两个系数：y = k₁x + k₂/x。

  • x = 1，y = −1：k₁ + k₂ = −1
  • x = −2，y = −5/2：−2k₁ − k₂/2 = −5/2，两边乘 −2 得 4k₁ + k₂ = 5
  • 相减：3k₁ = 6，k₁ = 2，k₂ = −3，所以 y = 2x − 3/x。
做完把两个点代回去检验，一分钟就能发现算错。

5. 函数的实际应用（方法 · 计算）

5.1 分段函数：每段分别算，再合并（作业 75 第 19 题 (3)，正确答案 47/3 小时）

  • AB 段：y = 2x + 10（0 ≤ x ≤ 5）。y ≥ 12 → x ≥ 1，得 1 ≤ x ≤ 5。
  • BC 段：y = 20（5 ≤ x ≤ 10），整段都在 12～20 之间。
  • CD 段：y = 200/x（10 ≤ x ≤ 24）。y ≥ 12 → x ≤ 50/3，得 10 ≤ x ≤ 50/3。
  • 三段连起来是 1 ≤ x ≤ 50/3，时长 50/3 − 1 = 47/3 小时。
步骤：写出每段的式子 → 每段解不等式 → 把区间接起来 → 末减初。

5.2 抛物线拱桥：以拱顶为原点建坐标系（作业 93 第 16 题，正确答案 2√6 米）

  • 拱顶为原点，设 y = ax²。水面距拱顶 2 米、宽 4 米 → 点 (2, −2) 在抛物线上 → a = −½。
  • 水位下降 1 米，水面离拱顶 3 米：令 y = −3，x² = 6，x = ±√6，宽 2√6 米。

5.3 配方求最值：x + 1/x 型（作业 75 第 21 题）

  • 阅读材料的方法：x > 0 时，x + 1/x = (√x − 1/√x)² + 2 ≥ 2，x = 1 时取最小值 2。
  • (2) x < 0 时：令 t = −x > 0，y = −(t + 1/t) = −[(√t − 1/√t)² + 2] ≤ −2，
    t = 1 即 x = −1 时 y 有最大值 −2。
  • (3) 车队过隧道：总路程 = 隧道长 + 车身总长 + 车距总和 = 185 + 10×4 + 9 × (1/9)v² = 225 + v²。
    时间 t = (225 + v²)/v = v + 225/v = (√v − 15/√v)² + 30 ≥ 30，v = 15 m/s 时用时最少，为 30 秒。
关键：遇到 「x + a/x」 就想到配方，最小值是 2√a，在 x = √a 时取到。

6. 坐标里的几何（方法）

6.1 一线三垂直（作业 93 第 10 题，你选 D，正确答案 C）

∠ACB = 90°，C 在 x 轴上 → 过 B 作 BD ⊥ x 轴，得到 △AOC ∽ △CDB（K 字形）。
OA = OC = 3，AC = 2BC → 相似比 2:1 → CD = OA/2 = 1.5，BD = OC/2 = 1.5。
B(4.5, 1.5)，k = 4.5 × 1.5 = 27/4。

看到「直角顶点在坐标轴上」，就向坐标轴作垂线，造相似（或全等）。

6.2 矩形对角线相等且互相平分（作业 92 第 10 题，你选 D，正确答案 C）

O 是矩形对角线的交点，所以 OA = OB，C 和 A 关于 O 对称。
设 AF = a，则 OB = 3a，A(4, a)。OA² = 16 + a² = 9a²，a = √2。
所以 C(−4, −√2)，选项 C 说 (−4, −1) 是错的。（D：面积 = 2 × ½ × BD × 4 = 24√2，是对的。）

选「不正确的」题：每个选项都算一遍，别凭感觉排除。
