1. 外心与内心（概念 · 易错）

是什么的交点性质
外心 O三边垂直平分线到三个顶点距离相等：OA = OB = OC
内心 I三个内角的角平分线到三条边距离相等

判断「O 是哪个三角形的外心」：找出到 O 距离相等的三个点就行。

  • 作业 13 第 6 题（你选 C，正确答案 B）：O 是△ABC 的外心 → OA = OB = OC；OCDE 是正方形 → OC = OE。
    所以 OA = OB = OE，O 是 △AEB 的外心。OD 是正方形的对角线，OD ≠ OC，所以 O 不是△ACD 的外心。

坐标里求外心（作业 13 第 5 题，正确答案 √5）：O(0,0)、A(2,0)、B(3,3)。

  • 先用最好算的那条垂直平分线：OA 的垂直平分线是 x = 1，设圆心 M(1, y)。
  • MO = MB：1 + y² = (1−3)² + (y−3)²，解得 y = 2。M(1, 2)，半径 = √(1+4) = √5。

两个角度公式（作业 92 第 15 题，你写 115°，正确答案 125°）：

  • 外心：∠A = ½∠BOC（同弧所对的圆周角是圆心角的一半）。∠BOC = 140° → ∠A = 70°。
  • 内心：∠BIC = 90° + ½∠A = 90° + 35° = 125°。
  • 补充：如果△ABC 是钝角三角形（O 在三角形外），∠A = 180° − 70° = 110°，∠BIC = 145°。
    题目没说锐角时，完整答案是「125° 或 145°」。

2. 垂径定理和「过一点的最短弦」（规律 · 方法）

  • 垂径定理：半径² = 弦心距² + 半弦²（r² = d² + (a/2)²）。
  • 过圆内一点 P 的弦：最长的是直径；最短的是垂直于 OP 的那条，长 2√(r² − OP²)。

作业 92 第 16 题（你写 9，正确答案 4√3）：

  • 圆心 D(2, 4) 到 y 轴的距离是 2，y 轴上的弦长 6，半弦 3 → r² = 2² + 3² = 13。
  • B(2, 3)，DB = 1。过 B 的最短弦垂直于 DB：半弦 = √(13 − 1) = √12 = 2√3，弦长 4√3。

3. 圆周角：证明时必须写「同弧（等弧）所对」（书写 · 易错）

  • 同弧（或等弧）所对的圆周角相等，都等于圆心角的一半；直径所对的圆周角是 90°。
  • 书写模板（圆周角作业第 4、5、6 题，老师都补了这一步）：
    > ∵ 弧 BC = 弧 BC（同弧），∴ ∠BDC = ∠BAC
    >
    > ∵ OC ⊥ AB，∴ 弧 AD = 弧 BD（垂径定理），∴ ∠APD = ½∠AOD
  • 怎么找角「所对的弧」：角的两条边夹住的、不经过角顶点的那段弧。
    作业 92 第 21 题老师的批注：∠B 所对的弧是 ADC，∠C 所对的弧是 BAD。

平行弦夹等弧（作业 92 第 21 题：AD ∥ BC，求证 AB = CD）——最短的证法：

连接 BD。∵ AD ∥ BC，∴ ∠ADB = ∠DBC（内错角）
∴ 弧 AB = 弧 CD（相等的圆周角所对的弧相等）∴ AB = CD

你一开始写了「∠DBC = ∠BDA」又划掉了——这条思路其实是对的，下次大胆写下去。

4. 阴影面积：等积转化（方法）

作业 92 第 7 题（你先写 A 又改成 B，正确答案 A）：

  • ∠ODE = 30° → ∠DOB = 60°；由对称，∠COB = 60°，∠AOC = 120°。
  • S△AOC = ½·r·r·sin120°，S△BOD = ½·r·r·sin60°，sin120° = sin60°，所以两个三角形面积相等。
  • 阴影 = △AOC + 弓形 BD = △BOD + 弓形 BD = 扇形 BOD（60°） = (60/360) × π × 2² = 2π/3。
  • 你最初的算式「1/6 × 2² × π」就是对的，有依据的第一感觉不要随便改。
阴影面积不规则时，先找面积相等的两块（全等、同底等高、对称），把阴影拼成扇形或三角形。

5. 切线的判定（方法 · 书写）

  • 直线和圆有公共点：连半径，证垂直。
  • 直线和圆没给公共点：作垂直，证半径（证明距离等于半径）。

作业 92 第 23 题 (2)（你只写了「连 OD、DE」）：AB 是直径，BC ⊥ AB，E 是 BC 中点，求证 DE 是切线。

连接 OD、BD。∵ AB 是直径，∴ ∠ADB = 90°，∴ ∠BDC = 90°。
∵ E 是 BC 中点，∴ DE = BE = ½BC（直角三角形斜边上的中线），∴ ∠EDB = ∠EBD。
∵ OD = OB，∴ ∠ODB = ∠OBD。
∴ ∠ODE = ∠ODB + ∠EDB = ∠OBD + ∠EBD = ∠OBE = 90°。
∵ OD 是半径，∴ DE 是⊙O 的切线。
关键链条：直径 → 90° → 斜边中线 → 等腰 → 两组等角相加 = 90°。

6. 证明垂直：转化成「两角之和 = 90°」（作业 92 第 20 题 (2)）

已知 OCDB 是正方形（第 (1) 问已证 BD ⊥ AB），要证 BE ⊥ OF。

① △AOE ≌ △DCE（AAS：∠AOE = ∠DCE = 90°，对顶角相等，OA = CD），所以 E 是 OC 中点。（这是老师批注的思路，可以接着用长度算；下面 ②～④ 是另一种只用角的证法）
② 正方形关于对角线 BC 对称，F 在 BC 上，所以 ∠FOC = ∠FDC。
③ CD ∥ AB，所以 ∠FDC = ∠EAO；又△AOE ≌ △BOE（OA = OB，OE 公共，直角），所以 ∠EAO = ∠EBO。
④ 于是 ∠FOC = ∠EBO，∠EBO + ∠BOF = ∠FOC + ∠BOF = ∠COB = 90°，所以 BE ⊥ OF。
思路：要证垂直 → 证两个角加起来是 90° → 用全等、对称、平行把角搬到一起。

7. 圆锥（公式 · 计算 · 易错）

展开图对应关系（最重要）：

圆锥侧面展开的扇形
母线 l扇形半径
底面周长 2πr扇形弧长
侧面积 πrl扇形面积
—圆心角 n = 360° × r / l
  • 高 h、底面半径 r、母线 l：l² = r² + h²。给的是直径就先除以 2！
  • 全面积 = 侧面积 + 底面积 = πrl + πr²。

作业 21 第 6 题（扇形半径 6、圆心角 120°，求侧面积和全面积）：
你把扇形半径 6 当成了圆锥的底面半径。正确做法：
S侧 = 120π × 6² / 360 = 12π；弧长 = 120π × 6 / 180 = 4π = 2πr，所以 r = 2；
S底 = 4π，S全 = 16π。

作业 21 第 7 题（底面直径 6 m，高 4 m）：

  • (1) 底面积 = π × 3² ≈ 28.26 m²，÷ 3 ≈ 9.4，最多住 9 人（你写 3）。
  • (2) 你用 6 当半径算出 l = 2√13，错了。r = 3，l = √(3² + 4²) = 5，S侧 = 15π，S底 = 9π，共 24π m²。

最短路径（作业 21 第 9 题 (3)）：小虫在曲面上走，不能沿底面圆周算弧长。

步骤：① 把侧面展开成扇形；② 用 n = 360° × r / l 求圆心角（这里 n = 360 × 2 / 8 = 90°）；
③ 在展开图里找到起点和终点，连线段；④ 用勾股定理（或特殊三角形）算长度。
